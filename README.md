## The entry

> One star. The bottle cap guards the fizz for months, earns one twist and one hiss, then lands in the bin before you've taken a sip — a lifetime of loyalty, zero seconds of fame.

A one-line, one-star review of a bottle cap (177 characters): the field is crowded with doorstops, rubber bands, paperclips, dustpans and tea towels, while no entry reviews the cap — yet its behaviour is instantly recognisable (months guarding the fizz, one twist, one hiss, straight in the bin), so the dullness itself carries the joke and the last words sharpen it instead of trailing off.

## How to run

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```

`main.py` (Python 3 stdlib only) validates the entry against the gate — UTF-8, 1–200 characters, single line, not only whitespace — writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), then reads the file back and verifies the bytes match exactly.
